 Hospital Management System (HMS)

A console-based Hospital Management System developed in C++ with persistent file handling, accompanied by Software Engineering (UML) architecture documentation.

Key Features
Patient Record Management: Register new patients, view all records, search by Patient ID, update details, and delete records with duplicate-ID checks.
Persistent File Storage: Saves and loads patient data automatically using C++ file handling (`patients.txt`).
System Design & Documentation: Includes Functional and Non-Functional Requirements, Spiral Model justification, Tools & Technologies, Project Timeline, and 4 UML Diagrams (Use Case, Class, Sequence, and Activity Diagrams).

 Repository Files
Hospital Management System.cpp - C++ source code for patient record management.
HMS_System_Design_and_UML.pdf - Software Requirements Specification (SRS) and UML design diagrams.

 Tools & Technologies
Language: C++ (Structures, Functions, Arrays, File Handling)
Modeling: UML (Use Case, Class, Sequence, Activity Diagrams)
Methodology: Spiral Process Model
